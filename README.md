## 🌟 Features

* **Side Panel Native**: Sits cleanly alongside your web browsing, instantly accessible with a click.
* **Smart Workspaces**: Save your current open tabs into isolated workspaces (e.g., "Research", "Travel", "Work").
* **Restore Instantly**: Open an entire workspace in one click. Tabsy automatically detects if a tab is already open so it never creates duplicates.
* **Beautiful Customization**: Express your spaces using **27 premium Lucide icons** and **18 modern color swatches**.
* **Global Shortcuts & Context Menus**: Hit \Ctrl+Shift+S\ (or \Cmd+Shift+S\ on Mac) to instantly stash your window, or right-click any page and select "Save to Tabsy".
* **Full Data Portability**: Export your workspace data as a JSON backup, and import it anywhere.
* **Dark Mode**: Gorgeous out-of-the-box Dark and Light mode themes that sync to your OS or can be toggled manually.

## 🚀 Getting Started

### Prerequisites

* Node.js (v18+)
* npm or yarn

### Installation

1. **Clone the repository:**
   \\\ash
   git clone https://github.com/yourusername/tabsy.git
   cd tabsy
   \\\

2. **Install dependencies:**
   \\\ash
   npm install
   \\\

3. **Build the extension:**
   \\\ash
   npm run build
   \\\
   *Note: This automatically generates all required extension icons from the source SVG.*

### Loading into Chrome

1. Open Chrome and navigate to \chrome://extensions/\.
2. Turn on **Developer mode** (top right corner).
3. Click **Load unpacked** and select the \dist\ folder that was generated by the build step.
4. Pin the extension to your toolbar and click the icon to open the Side Panel!

## 🔒 Privacy First

Tabsy runs entirely locally on your machine.
* **No Servers**: Your data never leaves your browser.
* **No Analytics**: We don't track your tabs, clicks, or workspaces.
* **Local Storage**: All workspaces are saved directly to Chrome's local storage.
